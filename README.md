# Fortgeschrittenes Praxisprojekt: COVID-19 und regionale Strukturmerkmale

**LMU München · Statistik · Wintersemester 2026/27**

## Projektübersicht

Das Projekt untersucht den Zusammenhang zwischen regionalen Strukturmerkmalen und altersspezifischen COVID-19-Inzidenzverläufen in Deutschland. Es wird von einer Gruppe aus fünf Studierenden im Rahmen des Fortgeschrittenen Praxisprojekts der LMU München durchgeführt.

Grundlage sind insbesondere COVID-19-Daten des Robert Koch-Instituts (RKI), regionale Bevölkerungsdaten und Gebietsklassifikationen des Bundesinstituts für Bau-, Stadt- und Raumforschung (BBSR). Für die Datenaufbereitung, explorative Analyse, statistische Modellierung und Visualisierung wird R verwendet.
